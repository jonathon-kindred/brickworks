Brickworks

Terraform for Databricks workspaces on AWS.

Set a naming convention, pick a compute mode, and get a repository that deploys one workspace per environment. Built from the provider's own AWS workspace guide. GitHub Actions with OIDC, no long-lived secrets.

Compute mode

Region

The Unity Catalog metastore must already exist in this region.

Naming convention

Tokens: {org} {workload} {env} {res}. Anything else is literal.

Environments

One workspace per environment, each with its own state and its own OIDC role.
