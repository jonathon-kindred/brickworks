BricksWork

Terraform for Databricks workspaces, generated.

Pick a cloud, set your naming convention, and get a complete repo — networking, workspace, Unity Catalog attachment and GitHub Actions with OIDC. No long-lived secrets.

Cloud

Compute

Naming convention

Lowercase letters and digits, 2–8 characters.
Tokens: {org} {workload} {env} {res}. Anything else is kept literally.

Environments

Resolved names

Indicative fixed cost

Per environment, list price, fixed hourly charges only. Excludes data processing, compute and storage. Check your own pricing calculator before quoting these.

Customer-managed keysCMK for managed services and workspace storage. Create-time only.
Audit log deliveryBillable usage and audit logs to your own bucket.
Budget policiesServerless compute can't carry cluster tags; cost attribution needs these.
